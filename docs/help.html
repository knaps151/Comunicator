What it is

Comunicator wraps public web clients — WhatsApp Web, Google Messages, Slack, Messenger, Telegram, or a custom HTTPS URL — in a multi-tab macOS window. Each account gets an isolated WebKit session, desktop notifications, and a dock badge when unread counts appear in the page title.

Unofficial third-party shell. Not affiliated with Meta, Google, Slack, Telegram, or Apple.

Install

Requires macOS 14+. The published Release zip is Apple Silicon (arm64).

  1. Download Comunicator.zip from GitHub Releases and unzip.
  2. Right-click Comunicator.app → Open → Open.
  3. If blocked: System Settings → Privacy & Security → Open Anyway.

Builds are ad-hoc signed and not notarized. Only install builds you trust. Optional: xattr -cr /path/to/Comunicator.app

Getting started

  1. Pick a service in the sidebar.
  2. Sign in inside the embedded browser as you would on the web.
  3. Use Custom URL… for another HTTPS messaging site.
  4. Add another login with ⋯ → Add Account… — cookies stay isolated per account.

Accounts and sessions

ActionWhat it does
Add AccountNew profile with its own cookies and storage
RenameDouble-click tab, context menu, or Session → Rename Tab…
Clear SessionWipes site data for that profile (signs you out in Comunicator)
Delete AccountRemoves profile, tab, and login data — cannot be undone

Tabs and shortcuts

ShortcutAction
⌘1–⌘9Switch to tab 1–9
⌘RReload active tab
⇧⌘RRename active tab
⇧⌘MMute / unmute notifications

Open tabs stay live in the background so unread can still update. Many tabs use more memory — Comunicator warns when a lot are open.

Notifications

  • Banners fire when the page title looks like it has unread counts — (3), 3 ·, or [3].
  • The dock badge aggregates unmuted tabs.
  • Mute from the toolbar or Session menu.
  • Click a notification to focus that tab.

Title-based only. Services that don’t put a count in the title may not badge or notify reliably.

Custom URLs

Must be HTTPS. Camera/mic and some SSO flows may be limited on unknown hosts; built-in services list allowed login domains.

Camera, microphone, and files

  • In-page calls use camera/mic after macOS permission prompts.
  • Capture is only granted for the main frame on allowed origins.
  • Downloads and uploads use standard macOS save/open panels.
